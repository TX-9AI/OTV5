# GENESIS — every revision shipped to OTV5

**One line per tarball, in order, from r0 (the seed).**
**Appended as part of the land command (WORKING_AGREEMENT §35), never after.**

This is not `git log`. Git records what changed; this records **why**, and it
keeps the corrections — a revision that exists because an earlier one was wrong
says so, and those are the entries worth reading. A revision absent from this
table did not happen. Revisions of other repositories are cited by prefix
(`dtp r489`), never by a bare number.
