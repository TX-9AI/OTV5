# GENESIS — every revision shipped to OTV5

**One line per tarball, in order, from r0 (the seed).**
**Appended as part of the land command (WORKING_AGREEMENT §35), never after.**

This is not `git log`. Git records what changed; this records **why**, and it
keeps the corrections — a revision that exists because an earlier one was wrong
says so, and those are the entries worth reading. A revision absent from this
table did not happen. Revisions of other repositories are cited by prefix
(`dtp r489`), never by a bare number.

| **r0** | r0 - THE SEED. One box trades one underlying intraday on Tastytrade: a candle feed writes the tape, plans read the tape and the chain and work out ahead of time the nearest setup that would clear their strategy's bars, strategies fire when price action satisfies a plan's completed vectors, the exit engine manages to stop, target or close, and every decision is recorded with its inputs and pushed to one warehouse. Telegram carries the alerts; a Claude Code agent runs on the box under a read-only brief. WHAT THIS SEED SHIPS, BEYOND THE TRADING PATH: (1) the unattended install leaves candle-feed and optionsbot installed and STOPPED and the warehouse push OFF; the data capture is always standalone; configure.sh's Done is the first start - the feed, then tools/prime_ramp.py primes the ramp from the warehouse (1m tape for the symbol and its extended-hours twin, 5m/15m/1h built from complete 1m buckets with the warehouse's complete higher-timeframe bars as the fallback, 1d from the study corpus), and a start whose priming fails is REFUSED; then the bot; the push is turned on only when tools/capture_guard.py (a live 14-day read of raw/trades and raw/candles) finds no other host pushing the symbol; a symbol switch drains the old symbol under its old label before the new one is primed. The repository a box installs from is named once, deploy/origin.conf, with two pinned copies that run before any clone exists (tests/check_origin.py). (2) EVERY READER OF A DERIVED TABLE JUDGES A ROW BY MARKET TIME - level_event.bar_close_epoch, surface_series.quote_ts, fork_series.bar_ts_ms, a level_sync mark the board fails closed without - never by the wall clock it was written at, so a primed store reads exactly like one the box wrote (tests/check_market_time.py). (3) the gap is measured from the store (the prior session's daily bar and today's 09:30 bar) and classified FLAT / UNDIRECTED / CONTINUATION / REVERSAL with the operator's size buckets and range-gap, record only (analysis/gap_class.py, tests/check_gap_measure.py). (4) the lander refuses to guess between two checkouts carrying the same markers and a spec names its repository with ORIGIN.
